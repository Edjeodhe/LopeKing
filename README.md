# 로프킹 (LopeKing) — 웹 프로토

산나비·카타나 제로풍 픽셀 횡스크롤 액션. 로프(갈고리) 액션이 핵심. 먼저 웹(캔버스, 빌드 없음)으로 시스템을 잡고 나중에 유니티로 옮긴다.
리깅·픽셀 굽기·이펙트 방식은 `../underworld-proto`(원더월드 프로토)를 참고했고, 그림·맵 구성은 새로 만들었다.

## 실행
```bash
python tools/server.py 5320
```
- 게임: http://localhost:5320/ · 리그 편집기: http://localhost:5320/rigedit.html
- 서버가 리그 편집기 저장(`POST /save`)과 확인용 스크린샷(`POST /shot` → `out/shots/`)을 받는다

## 조작
조작 방식은 두 가지이고 **Tab** 으로 바꿈 (브라우저에 기억 · 주소에 `?kb` / `?mouse` 로 강제). 기본 = 키보드만.

### 키보드만 (기본) — 마우스 버튼은 안 받음
| 키 | 동작 |
|---|---|
| 방향키 | 이동 · 조준(베기·로프·쿠나이 방향) · (실이 팽팽할 때) 위·아래 감기, 좌우 흔들기 |
| Space · Shift | 점프 · 대시 (아래 마우스 조작과 같음). 스윙 중엔 둘 다 **로프를 끊음** (로프 끝이 손으로 돌아옴) |
| Ctrl | 베기 — 누른 방향 쪽 (안 누르면 보는 쪽) |
| F | **로프**: 방향키 쪽(안 누르면 위 대각선) 걸 곳에 반드시 꽂힘 → 위면 바로 스윙. 꽂힌 뒤 다시 = 돌진 · 두 번 톡 = 꽂히자마자 돌진 |
| F (둘레 180px 에 적) | **쿠나이 → 귀보(鬼步)**: 실 없는 표식 쿠나이를 적마다 꽂음(삼태극 문양, 5초) → **F 다시** = 겨눈 쪽 표식 적부터 → 가까운 순으로 젠이츠 벽력일섬처럼 번개같이 꿰뚫고 지나가며 한 줄씩 그음 (그어진 적마다 피오라 옛 궁·검무처럼 순식간에 여러 번 베는 연출) → 다 지나간 뒤 그어진 적이 한꺼번에 베임 (마지막에 칼을 검집에 넣는 납도 — 딸깍 하는 순간 베임, 3명 이상이면 천천히) (Space·Shift 로 끊어도 그은 적은 베임, 두 번 톡 = 꽂히자마자). 이펙트는 초록 혼불. **쿨타임 5초** (왼쪽 위 스킬 칸에 표시, 쿨타임 중 F = 로프) |
| P/Esc 일시정지 · R 레벨 처음부터 · M 소리 · ` 디버그 (전체 화면은 브라우저 F11) |

### 마우스 조작
| 키 | 동작 |
|---|---|
| A/D | 이동 · (실이 팽팽할 때) 흔들기 |
| Space | 점프(누른 만큼 높이) · 공중에서 한 번 더 = 더블 점프 · 벽 차고 뛰기 · 매달린 벽 꼭대기면 턱 위로 올라섬 · 로프에서 뛰어내리기(실을 끊음) |
| Shift | 대시(무적, 방향키 8방향 · 입력 없으면 보는 쪽, 공중 1회) · 스윙 중이면 실을 끊고 대시 |
| 좌클릭 | 마우스 방향 베기 (공중에서는 그 방향으로 한 번 돌진) · 총알 되받아치기 |
| 우클릭 / E **톡** | 붉은 실 로프 던지기 → 벽·천장·대나무·고리·적에 꽂힘. **다시 누르면 그 자리로 순간 돌진**(지나는 길의 적을 관통해 벰, 적에 꽂혔으면 처형) |
| 우클릭 / E **꾹** | 꽂히는 순간까지 누르고 있으면 실이 팽팽 → 진자 스윙 (W/S 감기·풀기) |
| P/Esc 일시정지 · R 레벨 처음부터 · M 소리 · F 전체 화면 · ` 디버그 |

로프 액션 레퍼런스: INARI(1HP STUDIO) — "수리검을 던진 위치로 즉시 이동하는, 이동과 결합한 전투".
벽에 도착하면 0.6초 매달리고(벽 점프·다음 투척으로 연쇄), 천장은 0.35초, 대나무 줄기는 몸이 통과하고 로프만 꽂혀 붙잡고 매달림. 주인공 이펙트(베기·대시·돌진·이단 점프·불티)는 전부 초록 (모양은 그대로, 색만).

## 기본 수치
- 내부 해상도 480×270 정수배 확대, 물리 120Hz 고정 스텝, 타일 16px
- 캐릭터: SD 비율 = 원더월드 사막 은둔자와 같은 방식(그림은 길쭉하게 나와도 `rig.json` 부위 `size` 로 머리를 키우고 다리를 줄임, 머리 ≈ 키의 35%), 서 있는 키 약 44px
- 전투: 산나비식 HP(주인공 5칸, 맞으면 1초 무적), 구울 2타·조총 구울 1타, 로프 돌진 관통·처형·귀보는 즉사
- 레벨: 1-1 달빛 지붕길 → 1-2 불타는 성문길(보스: 참수터의 망나니). 체크포인트(돌 등롱)에서 부활, 보스전 중 죽으면 보스도 처음부터

## 원더월드에서 가져온 방식
- **칼끝 궤적 이펙트**: 리그가 칼을 그릴 때 손잡이·칼끝 자리를 기록(`rig.js blade`) → 휘두르는 동안의 자리를 이어 부채꼴을 도트로 칠함(`fx.js drawSmear`). 이펙트가 모션을 그대로 따라감
- **픽셀 = 코드**: AI 그림을 그대로 쓰지 않고 `bake.js` 규칙으로만 픽셀이 생김. 이펙트도 1px 도트·체크무늬 소멸
- **리깅**: 부위 PNG + 관절 좌표(rig.json, 칸 px) + 뼈 각도 모션. 레이어 순서는 `rig.js LAYERS` 한 곳
- **사망 = 통 이미지**: 리깅으로 어색한 쓰러짐은 4컷 통그림(`art/assassin/death/`)을 같은 굽기로
- **이펙트 안에 캐릭터**: 고리 이펙트의 먼 반(위)은 캐릭터 뒤, 가까운 반(아래)은 캐릭터 앞에 그림 (`fx.js ring`)
- **통 이미지와 비교 리깅**: 통 이미지(차렷 자세)를 같이 뽑아 두고, 잘라 낸 부위를 차렷 자세로 조립해 겹쳐 봄(IoU) + 자동 맞춤

## 그림 파이프라인 (Codex CLI)
1. `tools/char_prompts.py` 에 캐릭터 설명 추가 (같은 뼈대: head·torso·hips·cape·upperArm·foreArm·thigh·shin + 무기)
2. `sh tools/gen_char.sh <id>` → `art/<id>/full_side.png`(통 이미지) → 그걸 참고로 `parts_side.png`(4×2 부위 시트) · `weapon.png` · (`death.png` 4컷)
3. `python tools/slice_char.py art/<id>` → 마젠타 배경 제거, 덩어리 단위로 부위 자르기, 관절 초안, `rig.json`
   (이미 맞춘 관절을 지키며 그림만 다시 자르려면 `--keep-joints`)
4. 리그 편집기에서 **자동 맞춤(통 이미지 기준)** → 남은 곳은 점을 끌어 맞춤 → 저장. "모션 한 장 보기"로 전 모션 확인
   (비교·자동 맞춤은 부위 배율 없이 통 이미지와, 피벗은 그 부위 그림 안에서만 움직임)
5. SD 비율: `rig.json` 부위 `size` 로 머리 키우고 다리 줄이기(은둔자 방식). 사망 컷은 SD로 조립한 `sd_ref.png` 를 참고로 뽑음
6. 게임 `main.js boot()` 의 `loadActorType('art/<id>')` 로 연결 (rig.json 이 없으면 임시 그림으로 돈다)

현재 캐릭터: `assassin`(주인공: 삿갓·흰 코트·붉은 띠·망토·흑도) · `ghoul`(구울 검객: 도롱이) · `gunner`(조총 구울: 전립·도자기 가면) · `executioner`(보스: 붉은 탈·쇠사슬·처형 깃발·참수도, 1.9배)
`art/assassin/v0_real/` = 처음 뽑은 사실 비율 버전(참고용, 안 씀)

## 맵
`levels/*.json` = 사각형 채우기(`rects: [x, y, w, h, 타일]`) + 점(`points: [x, y, 종류]`). 그림이 아니라 데이터라 유니티 타일맵으로 그대로 옮길 수 있다.
타일: `#` 돌(로프 O) · `B` 기와(로프 O) · `M` 쇠벽(로프 X) · `Z` 대나무 줄기(몸 통과, 쿠나이 O) · `=` 나무 발판(위에서만) · `^` 가시. 점: player · grunt · gunner · boss · ring(갈고리 고리) · lamp · check(체크포인트) · exit. `gates` = 보스 방 문
`?level=1` 처럼 주소에 붙이면 타이틀 없이 그 레벨로 바로 시작

## 자동 확인
게임 탭 콘솔에서 `tools/autotest.js` 를 불러 `T.key / T.aim / T.press / T.run(초) / T.shot(이름)` 으로 조작·스크린샷.
화면이 가려져 rAF 가 멈춰도 `__G.advance(초)` 로 시간이 흐른다.
