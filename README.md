# 로프킹 (LopeKing) — 웹 프로토

산나비·카타나 제로풍 픽셀 횡스크롤 액션. 로프(갈고리) 액션이 핵심. 먼저 웹(캔버스, 빌드 없음)으로 시스템을 잡고 나중에 유니티로 옮긴다.
리깅·픽셀 굽기·이펙트 방식은 `../underworld-proto`(원더월드 프로토)를 참고했고, 그림·맵 구성은 새로 만들었다.

## 실행
```bash
python tools/server.py 5320
```
- 게임: http://localhost:5320/ · 리그 편집기: http://localhost:5320/rigedit.html
- 서버가 리그 편집기 저장(`POST /save`)과 확인용 스크린샷(`POST /shot` → `out/shots/`)을 받는다

## 조작
| 키 | 동작 |
|---|---|
| A/D | 이동 · (로프에 매달렸을 때) 흔들기 |
| Space | 점프(누른 만큼 높이) · 벽 차고 뛰기 · 로프에서 뛰어내리기 |
| Shift | 대시(무적) · 로프에 매달렸을 때 = 갈고리 쪽으로 당겨 날기 |
| 좌클릭 | 마우스 방향 베기 (공중에서는 그 방향으로 한 번 돌진) · 총알 되받아치기 |
| 우클릭 / E (누르고 있기) | 로프 발사 → 벽·고리에 걸면 진자 스윙, 적에게 걸면 끌려가 처형 |
| W/S | 로프 감기·풀기 |
| R 다시 · F 전체 화면 · ` 디버그 |

## 기본 수치
- 내부 해상도 480×270 정수배 확대, 물리 120Hz 고정 스텝, 타일 16px
- 캐릭터: 약 3.3등신 SD(원더월드 사막 은둔자 비율), 서 있는 키 약 44px
- 전투: 산나비식 HP(주인공 5칸, 맞으면 1초 무적), 구울 2타·조총 구울 1타, 로프 처형은 즉사

## 구조 (`src/`)
| 파일 | 하는 일 |
|---|---|
| `main.js` | 게임 루프 · 전투 판정 · 로프 대상 찾기 · 카메라 · 그리기 순서 · HUD |
| `player.js` | 이동(코요테·점프 버퍼·벽 타기)·대시·로프(fly → hook 진자 / zip 당겨 날기·처형)·베기. 수치는 `TUNE` |
| `enemies.js` | 구울 검객(순찰→추격→예고→베기) · 조총 구울(거리 유지→붉은 조준선 예고→발사) |
| `rig.js` | 컷아웃 리그(옆모습 전용). 부위 PNG를 뼈 각도대로 SS(4)배 캔버스에 그림. 망토는 세로 3마디 사슬. 칼끝·손·발 소켓 기록 |
| `anim.js` | 모션 = 뼈 각도 데이터(대기·달리기 8장·점프·벽·대시·로프 매달림·마우스 방향 베기 30fps). 망토 사슬 물리 `stepCape` |
| `bake.js` | **픽셀 굽기(코드 셰이더)**: 고해상도 → 박스 평균 → 알파 이진화 → 고정 팔레트(k-means) → 셀 음영 띠 → 외곽선. 원더월드 그대로 |
| `actor.js` | 캐릭터 종류(rig.json + 부위 + 팔레트) 읽기, 개체마다 굽기 캔버스, 사망 통그림 굽기, 잘린 조각 굽기 |
| `gore.js` | 잔혹 연출: 참수·두 동강·팔 절단·처형(사지 분산)·고꾸라짐. 조각은 `pose.only/hide`로 그 부위만 다시 구워 날림, 그루터기에서 피가 뿜어짐 |
| `fx.js` | 칼끝 궤적(smear) · 몸을 감싸는 고리(뒤 반/앞 반 나눠 그림) · 입자 · 피 자국(타일에 영구히 묻음) · 속도선 · 번쩍임 |
| `world.js` | 타일 충돌 · 한쪽 발판 · 가시 · 로프 레이캐스트(DDA) |
| `scenery.js` | 타일·배경(달밤 기와 마을)·등불·갈고리 고리를 코드로 도트 그림 |
| `placeholder.js` | 그림 없는 캐릭터용 임시 부위(코드 그림) — 같은 파이프라인으로 돌리기 위함 |
| `rigedit.js` | 리그 편집기 |

## 원더월드에서 가져온 방식
- **칼끝 궤적 이펙트**: 리그가 칼을 그릴 때 손잡이·칼끝 자리를 기록(`rig.js blade`) → 휘두르는 동안의 자리를 이어 부채꼴을 도트로 칠함(`fx.js drawSmear`). 이펙트가 모션을 그대로 따라감
- **픽셀 = 코드**: AI 그림을 그대로 쓰지 않고 `bake.js` 규칙으로만 픽셀이 생김. 이펙트도 1px 도트·체크무늬 소멸
- **리깅**: 부위 PNG + 관절 좌표(rig.json, 칸 px) + 뼈 각도 모션. 레이어 순서는 `rig.js LAYERS` 한 곳
- **사망 = 통 이미지**: 리깅으로 어색한 쓰러짐은 4컷 통그림(`art/assassin/death/`)을 같은 굽기로
- **이펙트 안에 캐릭터**: 고리 이펙트의 먼 반(위)은 캐릭터 뒤, 가까운 반(아래)은 캐릭터 앞에 그림 (`fx.js ring`)
- **통 이미지와 비교 리깅**: 통 이미지(차렷 자세)를 같이 뽑아 두고, 잘라 낸 부위를 차렷 자세로 조립해 겹쳐 봄(IoU) + 자동 맞춤

## 그림 파이프라인 (Codex CLI)
1. `tools/char_prompts.py` 에 캐릭터 설명 추가 (같은 뼈대: head·torso·hips·cape·upperArm·foreArm·thigh·shin + 무기)
2. `sh tools/gen_char.sh <id>` → `art/<id>/full_side.png`(통 이미지) → 그걸 참고로 `parts_side.png`(4×2 부위 시트) · `weapon.png` · (`death.png` 4컷)
3. `python tools/slice_char.py art/<id>` → 마젠타 배경 제거, 덩어리 단위로 부위 자르기, 관절 초안, `rig.json`
   (이미 맞춘 관절을 지키며 그림만 다시 자르려면 `--keep-joints`)
4. 리그 편집기에서 **자동 맞춤(통 이미지 기준)** → 남은 곳은 점을 끌어 맞춤 → 저장. "모션 한 장 보기"로 전 모션 확인
5. 게임 `main.js boot()` 의 `loadActorType('art/<id>')` 로 연결 (rig.json 이 없으면 임시 그림으로 돈다)

현재 캐릭터: `assassin`(주인공: 삿갓·흰 코트·붉은 띠·망토·흑도) · `ghoul`(구울 검객: 도롱이) · `gunner`(조총 구울: 전립·도자기 가면)
`art/assassin/v0_real/` = 처음 뽑은 사실 비율 버전(참고용, 안 씀)

## 맵
`levels/*.json` = 사각형 채우기(`rects: [x, y, w, h, 타일]`) + 점(`points: [x, y, 종류]`). 그림이 아니라 데이터라 유니티 타일맵으로 그대로 옮길 수 있다.
타일: `#` 돌(로프 O) · `B` 기와(로프 O) · `M` 쇠벽(로프 X) · `=` 나무 발판(위에서만) · `^` 가시. 점: player · grunt · gunner · ring(갈고리 고리) · lamp · exit

## 자동 확인
게임 탭 콘솔에서 `tools/autotest.js` 를 불러 `T.key / T.aim / T.press / T.run(초) / T.shot(이름)` 으로 조작·스크린샷.
화면이 가려져 rAF 가 멈춰도 `__G.advance(초)` 로 시간이 흐른다.

## 유니티로 옮길 때
- `rig.json`·부위 PNG·사망 컷은 그대로 `Resources`로. 모션(`anim.js`)은 각도 데이터라 C#으로 옮기기 쉬움
- `bake.js` 굽기 규칙은 오프라인 굽기 또는 렌더 텍스처 + 컴퓨트/프래그먼트 셰이더로 (같은 순서: 박스 평균 → 알파 이진화 → 팔레트 → 음영 띠 → 외곽선)
- 물리는 고정 스텝(120Hz) 기준 수치(`player.js TUNE`)라 `FixedUpdate` 로 옮김
